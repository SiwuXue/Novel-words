# 语音朗读（TTS）· 实现计划

> 状态：**一期已完成**（2026-09-17，提交 f931114）
> 参考：用户提供的阅读类 TTS 配置面板截图（服务商/语速/音调/音量/朗读方案/试听）
> 决策：一期做 **Edge TTS + 系统语音**；读完**自动连播下一章**；**逐词视图同样支持**
>
> 一期落地要点：
> - Edge TTS 版本串必须用 **143.0.3650.75**（130 会被 403），需携带 Sec-MS-GEC / Sec-MS-GEC-Version / Sec-CH-UA 头
> - 当前网络环境干扰微软语音端点（连接被重置），**默认服务商为 system**；换网络/代理后可用 `cargo test --lib -- --ignored` 验证真实合成
> - 句子切分逐句返回不合并（原 buffer 拼接逻辑会在总长<300 时把句子拼回去，已修复）

## 一、目标

阅读模式支持整章语音朗读：逐句合成播放、当前句高亮跟随、自动连播下一章；设置页提供服务商/语速/音调/音量/音色配置与试听。一期覆盖单音色；多角色（旁白/对白分音色、AI 识别人物性别）放二期。

## 二、服务商（一期两个）

| 服务商 | 说明 | 实现 |
|---|---|---|
| **Edge TTS** | 微软在线 neural 音色（云健/云希/晓晓/Aria/Guy 等），免 key 需联网，输出 MP3 | Rust 端 WebSocket 客户端合成（按句请求），字节返回前端 audio 播放 |
| **系统合成语音** | WebView2 speechSynthesis，离线零配置 | 前端直接调用，支持 rate/pitch/volume |

预留 Provider 抽象：阿里云 DashScope（Qwen3-TTS）、MiniMax 二期按 API 密钥接入；SAPI5 暂缓。

## 三、一期功能清单

1. **Rust `tts.rs`**
   - Edge TTS WebSocket 客户端：连接 → SSML 请求 → MP3 字节（带超时与重试一次）
   - 命令 `tts_synthesize(text, voice, rate, pitch, volume) -> Vec<u8>`；短句限长（按句切片由前端负责）
   - 音色清单常量（中文：晓晓/云健/云希…；英文：Aria/Guy…），按语言给默认音色
2. **前端朗读引擎 `src/utils/ttsPlayer.ts`**
   - 句子切分 → 播放队列；系统语音走 speechSynthesis、Edge 走 audio
   - 播放令牌（token）：切章/退出/手动停止立即中断队列与合成
   - 事件：onSentenceStart（高亮+滚动跟随）、onFinish（连播下一章）
3. **阅读器集成**
   - 普通阅读模式（Tiptap）与逐词视图（WordTapReader）工具条各加「朗读/暂停/停止」
   - 朗读中当前句高亮并滚动跟随；逐词视图高亮当前句内已着色单词不冲突
   - 读完自动连播下一章（可关，设置 tts_auto_next）；无下一章提示结束
   - 挂载了音频文件的小说：朗读按钮仍可用（用户自选），不强制
4. **设置页「朗读」区**
   - 服务商（edge/system）、语速/音调/音量滑杆（0.5–2.0，音量 0–100%）、音色下拉、自动连播开关
   - 试听按钮（固定示例句，当前服务商+音色合成即播）
   - 持久化 app_settings：tts_provider / tts_voice / tts_rate / tts_pitch / tts_volume / tts_auto_next
5. **i18n** 中英文案

## 五、风险与对策

| 风险 | 对策 |
|---|---|
| Edge TTS 为微软非公开接口，可能失效/限流 | 合成失败自动回退系统语音并提示；系统语音离线兜底 |
| WebView2 speechSynthesis 音色取决于系统语音包 | 设置页提示安装系统语音包 |
| 长句合成慢 | 前端按句切片 + 预取下一句 |
| 切章/退出后播放不停 | 播放令牌 + 卸载清理 |
