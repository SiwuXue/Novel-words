# 英文逐词阅读模式 · 实现计划

> 状态：**一期已完成**（2026-09-17）
> 参考：obsidian-language-learner（LingQ 同款交互）
> 范围：**仅对英文小说（novel.language === 'en'）生效**

## 已确认决策

1. 快捷标记沿用现有三档：不认识=unknown / 模糊=familiar / 认识=mastered
2. "忽略"（ignore）档一期就加：user_vocab 表 CHECK 迁移扩展（schema v2，自动备份机制已覆盖）
3. 词组（Phrase）推到二期
4. 阅读方式：整章滚动 + 懒加载续页（不用翻页模式）
5. 标记写入 user_vocab（个人总词汇库，跨词汇本共享；未收录词直接建个人条目，不入词汇本）

## 一、目标

在英文小说的专注阅读模式下提供"逐词阅读"能力：全文每个单词可点击、按学习状态着色、点击即查词并就地标记熟练度，解决"新词无反馈、标记要切页"的割裂体验。

## 二、现状与切入点

| 现状 | 位置 |
|------|------|
| 专注阅读模式（样式态切换） | `NovelEditorPage.vue`（`reading-mode` class，含阅读进度记忆） |
| 划词查词弹窗 | `NovelEditor.vue` → `DictLookupPopover.vue`（mouseup 选中文本触发） |
| 词汇熟练度 | 三档：unknown / familiar / mastered（`VocabWord.proficiency`） |
| 已收录词高亮 | `get_highlight_words` + 编辑器高亮（只亮已收录词） |
| 小说语种 | `Novel.language: 'zh' \| 'en'` |

**功能添加位置：`NovelEditorPage.vue` 的专注阅读模式内**，新增一个"逐词"开关按钮（仅英文小说显示）。开启后阅读区从 Tiptap 编辑器切换为只读的逐词渲染视图（复用章节内容数据，不改动编辑器与数据结构）；关闭则回到现有编辑器。查词弹窗 `DictLookupPopover` 原样复用，只扩展快捷标记按钮。

## 三、一期功能清单

1. **逐词渲染器**（新组件 `WordTapReader.vue`）
   - 章节文本按段落 → 句子 → 单词分词，渲染为 `<span class="wt-word">` 树
   - 英文分词用规则实现（`[A-Za-z''-]+` + 常见缩写处理），不引入 NLP 依赖
   - 分页渲染（每页 N 段，默认整章按 ~40 行懒加载），防长章节上万节点卡顿
2. **状态着色**（对接现有数据）
   - 未收录 → 新词色（蓝）；unknown → 红；familiar → 黄；mastered → 灰绿；新档 ignore → 淡灰
   - 颜色走主题 CSS 变量，深浅色主题各一套
3. **点击单词 → 查词 + 快捷标记**
   - 复用 `DictLookupPopover`，新增三个快捷按钮：不认识 / 模糊 / 认识，点击直接写库并刷新全文颜色
   - 收词入词汇本逻辑复用现有（默认收进当前高亮所选词汇本）
4. **"忽略"档**（需数据库迁移）
   - 新增 proficiency 值 `ignore`，用于专有名词/无需学习的词；不进入复习队列与生词统计
   - 走现有"升级前备份"机制做 DDL 迁移
5. **计数条 + 读完操作**
   - 顶栏显示本章：新词 / 学习中 / 已掌握 / 已忽略 实时计数
   - "读完本章"按钮：剩余新词一键标 ignore（可撤销）

## 五、技术要点与风险

| 点 | 方案 |
|----|------|
| 分词一致性 | 同一单词在全文着色按小写归一；查词传原文（保留大小写） |
| 性能 | 懒渲染 + 分页；单页 ≤ 500 词，滚动到底自动加载下一页 |
| 数据库 | ignore 档：检查现有 DDL/迁移代码后决定是 CHECK 约束放宽还是纯值扩展；升级前自动备份 |
| 与编辑器共存 | 逐词视图为只读渲染层，编辑能力保留在关闭开关后的原编辑器 |
| 复习侧影响 | ignore 不进复习队列；复习页筛选逻辑需同步排除 |
